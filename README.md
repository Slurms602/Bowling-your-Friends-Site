# Bowling your Friends: website

The download page for **Bowling your Friends**: https://slurms602.github.io/Bowling-your-Friends-Site/

Plain HTML/CSS/JS served by GitHub Pages. Download buttons point at
`releases/latest/download/BowlingYourFriends-Windows.zip` (and `-Linux.zip`), so publishing a new release with the
same asset names updates the site's downloads automatically. Bump the version and size text in `index.html` when you do.
